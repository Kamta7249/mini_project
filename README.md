# Email Spam Detection Using Machine Learning

## Project Overview
This project uses Artificial Intelligence and Machine Learning to classify text messages as Spam or Ham (Genuine).

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
Multinomial Naive Bayes

## Dataset
UCI SMS Spam Collection Dataset.

## Project Workflow
1. Dataset collection
2. Data preprocessing
3. Text feature extraction using TF-IDF
4. Model training
5. Model testing
6. Performance evaluation
7. Spam message prediction

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## How to Run
1. Download the Jupyter Notebook.
2. Open it using Google Colab.
3. Run all cells.
4. Enter custom messages to test spam detection.

## Expected Outcome
The trained model predicts whether a given message is Spam or Ham.
